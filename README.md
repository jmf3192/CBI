# CBI

CBI sera la plataforma base para evaluar la competitividad de proyectos frente a convocatorias de financiacion publica.

El proyecto arranca con una arquitectura inicial documentada en [`docs/arquitectura.md`](docs/arquitectura.md).

## Objetivo

Construir una aplicacion web con:

- Acceso por usuario y contrasena.
- Convocatorias activas visibles segun permisos.
- Cuestionarios para estimar la puntuacion de un proyecto.
- Comparacion frente a competidores y datos CSV.
- Panel admin para usuarios, accesos, convocatorias y datasets.
- Creacion de nuevas convocatorias mediante cambios versionados con Codex.
